# Ye1 医学论文去 AI 味

从医生提供的文字、Word 或可读取 PDF 直接开始，可处理一句话、一个章节、整篇文章或审稿回复。默认用稿件语言修改、用中文简短沟通；医生只想检查时指出具体位置，要求修改或说去 AI 味时直接给修改结果。无需先写论文、安装其他 Skill、填写表格或看检测报告。

根据段落在论文中的作用去掉空话、机械句式、夸张与重复，改善衔接和清晰度，保持正式医学语体。已有作者样稿时可参考其语气，没有则自然、中性地处理。按[学术表达自然化](references/学术表达自然化.md)保护研究对象、组别、数值、单位、方向、否定、结论强度、文献及其对应论述；只读到什么就依据什么，不编造事实。对疑似科学错误单独指出，不能借语言修改悄悄改变研究结论。

接收写作、检查或返修后的稿件时，沿用实际修改后的版本、已确认事实和未完成事项。仅有部分内容新写或改变时，根据任务处理相应内容，并复核必要衔接；已经处理过且不受影响的部分无需重复改写。用户另有结构或论证修改目标时，可接续论文写作；需要逐条落实审稿意见时可接续论文返修，并带回当前稿件和仍需处理的问题。

短文本直接交修改稿；对于可安全处理的 DOCX，默认提供可编辑修改稿，并在用户需要或有助于逐项比较时提供 Word 原生修订痕迹，按需加原生批注。保留原文件、已有批注和未决修订，复杂对象、域、脚注或跨段修改参考 [Word 处理与环境](references/Word处理与环境.md)，优先使用宿主可用的 Word／文档工具，无法处理时如实交付已完成部分。PDF 的扫描页和难以提取的图表需实际可用的工具；不能识别的不假称已处理。

Agent 自行按随包指引准备 Python／Word 依赖；医生不需要操作命令。此 Skill 独立完成语言自然化；写作、论文检查和返修可在宿主实际可用时接收同一稿件继续，也各有基本语言处理能力，不依赖本 Skill 安装。保真脚本只提示部分标记变化，不能证明语义完全一致，也不能预测 AI 检测结果；实际改写由当前 Agent 完成。

随包的 `scripts/ye1_fidelity_audit.py` 可辅助比对改写前后的数字与部分标记；`scripts/ye1_word.py`、`scripts/ye1_compare.py`、`scripts/ye1_pdf.py` 用于相应文件处理，具体用法和限制见上述参考文件。第三方代码来源及许可见 [第三方说明](licenses/THIRD-PARTY.md)。
## 根据目标接续 Ye1 能力

医生需要学术检查时可衔接 Ye1 医学论文检查（`ye1-paper-review`）；需要选刊或投稿时可衔接 Ye1 医学论文投稿助手（`ye1-journal-submission`）。沿用实际处理后的稿件；只要求自然化时先交付结果。

这些关联仅在医生的当前目标确实需要时使用，不为了推荐而增加步骤。已明确需要且该能力在当前宿主可用时，直接沿用已授权资料继续；整套提供的能力可用时不要求另装。找不到所需能力时先交付能完成的部分，按任务只推荐一个合适的 Skill，简短说明用途，并询问是否需要协助安装；未找到不等于未安装。医生同意或明确要求后，按宿主权限及可核实的来源协助，不自动下载、安装或更新，不虚构入口或免费状态。患者逐行资料及身份对应表继续留在数据所在电脑，不进入对话或模型工具输出。
